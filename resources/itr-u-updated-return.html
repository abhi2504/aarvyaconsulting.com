ITR-U — the updated return you didn't know you could file

Forgot to file? Missed income? Filed wrong form? ITR-U lets you fix old returns up to 24 months later — for a fee.

🪙 In 60 seconds
  • ITR-U = Updated Return under Section 139(8A). Introduced Apr 2022.
  • File up to 24 months after end of relevant AY. Add additional 25% (within 12 months) or 50% (within 24 months) on tax + interest.
  • Can declare additional income, but cannot reduce income or claim refund.
  • Useful when you receive AIS notice about missed income, or want to disclose proactively.

When to use ITR-U

  • You didn't file an ITR earlier (skipped it) — now want to file
  • You filed but missed reporting some income (AIS now shows it)
  • You filed wrong head of income (e.g., capital gain shown as other sources)
  • You want to proactively disclose foreign assets earlier missed
  • You want to set off old losses you forgot to claim

When you CAN'T file ITR-U

  • To claim a refund (only to disclose more, not less)
  • To reduce your tax liability
  • To increase loss / carry-forward (with some exceptions)
  • When a search / requisition has been initiated against you
  • When assessment/reassessment/recomputation is pending
  • For the same AY, only once

Additional tax on ITR-U

Filing ITR-U costs more than the original ITR. You pay:

Time of filingAdditional tax
Within 12 months of end of AY25% of (tax + interest)
Within 12–24 months of end of AY50% of (tax + interest)

Example

You missed reporting ₹3L FD interest in FY 22-23 ITR. AIS now shows it. You file ITR-U in Aug 2025 (within 12 months of end of AY 23-24).

  • Extra tax on ₹3L at 30% = ₹90,000
  • Interest u/s 234A/B/C (rough): ₹15,000
  • Additional tax (25%) on ₹1,05,000 = ₹26,250
  • Total payable = ₹1,31,250

Painful but cheaper than a 270A penalty (50-200% of tax) + interest + possible prosecution if uncovered later.

How to file ITR-U

  1. Login to e-Filing

  2. e-File → Income Tax Returns → File Income Tax Return

  3. Pick AY, ITR form, mode "Online", filing section "Updated Return u/s 139(8A)"

  4. System pre-fills based on previous return + AIS data

  5. Add the additional income

  6. Compute additional tax (25% or 50%) — system computes

  7. Pay tax via challan, then submit ITR-U with verification

ITR-U is the IT department's olive branch — disclose voluntarily, pay an extra 25-50%, and the case closes. Wait for them to find out and you pay 100-200% penalty plus possible prosecution. The math favours disclosure.
